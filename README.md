# ゼロブレイド：剣霊と共に舞う（Unity 3Dアクション）

## 概要

Unityで開発した3Dアクション×Roguelikeゲームのデモです。

回避・パリィを軸としたリズム型戦闘システムを実装しました。

miHoYo第1回ゲーム企画コンテストとして参加しました。

- 開発期間：20日（2025/10/20〜11/10）

- 開発人数：1人


## 担当内容

本プロジェクトは個人制作であり、以下をすべて担当しました：

- ゲームシステム設計（戦闘・成長・剣霊システム）

- プレイヤー操作・カメラ制御（TPS）

- UIシステム実装

- 剣気・スキルシステム実装

- シェーダー調整（UTS3 Toon + URP）

- イベント駆動型アーキテクチャ設計（EventQueue）


## 技術的な工夫

- 行動駆動型成長システム

  - 数値ではなく「回避・パリィ成功」によってリソースを獲得する設計
  
  - プレイヤースキルとゲーム進行を強く結びつけた
  
- EventQueue（Pub/Sub）による疎結合設計

  - スキル・演出・UIをイベントベースで連携
  
  - 機能追加時の拡張性を向上
  
- UniTaskによる非同期処理

  - スロー演出やスキル発動のタイミング制御を実装
  
- シェーダーによる表現強化

  - URP + Toon Shaderを用いたキャラクターとステージ表現
